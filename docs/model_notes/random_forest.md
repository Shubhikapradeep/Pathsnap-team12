# Random Forest — PathSnap

## Model
RandomForestClassifier from scikit-learn.

## Configuration
- Estimators: 200
- Maximum depth: 20
- Minimum samples per leaf: 5
- Random state: 42
- Parallel jobs: -1
- Training row cap: 800,000

## Evaluation
The experiment used 5-fold GroupKFold, grouping by trip.

| Metric | Result |
|---|---:|
| CV macro F1 | 0.9314 ± 0.0145 |
| CV top-1 | 0.8736 |
| CV route continuity | 0.9328 |
| Student-test macro F1 | 0.9347 |
| Student-test top-1 | 0.8776 |
| Student-test log loss | 0.0319 |
| Student-test route continuity | 0.9269 |
| Fit time | 156.9 seconds |
| Inference time per observation | 0.066 ms |

## Notes
Random Forest achieved the highest student-test macro F1 among the two
models evaluated in this experiment. It also achieved lower log loss and
higher top-1 accuracy and route continuity than Extra Trees.
