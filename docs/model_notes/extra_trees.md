# Extra Trees — PathSnap

## Model
ExtraTreesClassifier from scikit-learn.

## Configuration
- Estimators: 200
- Minimum samples per leaf: 5
- Random state: 42
- Parallel jobs: -1
- Training row cap: 800,000

## Evaluation
The experiment used 5-fold GroupKFold, grouping by trip.

| Metric | Result |
|---|---:|
| CV macro F1 | 0.9272 ± 0.0132 |
| CV top-1 | 0.8679 |
| CV route continuity | 0.9273 |
| Student-test macro F1 | 0.9269 |
| Student-test top-1 | 0.8733 |
| Student-test log loss | 0.0342 |
| Student-test route continuity | 0.9240 |
| Fit time | 44.7 seconds |
| Inference time per observation | 0.0798 ms |

## Notes
Extra Trees trained faster than Random Forest in this experiment.
However, its student-test macro F1, top-1 accuracy and route continuity
were slightly lower, while its log loss was higher.
